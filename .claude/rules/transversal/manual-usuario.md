# Manual de usuario por pantalla
- Cada pantalla funcional de `src/app/features/` mantiene su página de manual asociada en documentación.
- Si una tarea modifica flujos visibles, campos o acciones del usuario, actualiza la página de manual correspondiente en el mismo plan.
- Si el cambio fue solo interno y la UI no varió, registra `revisado: YYYY-MM-DD` sin reescribir contenido.
- El tier `barrido` redacta o actualiza el borrador del manual; el tier `razonamiento` lo revisa contra el comportamiento real.
**Por qué:** pendiente de documentar.
